# Home

> **Capture without classification; classify and synthesize when useful.**

| Layer | Question it answers | Where |
|---|---|---|
| Quick Notes | What did I think? | `Daily/YYYY-MM-DD HHmm` |
| Daily | What did I think today? | `Daily/YYYY-MM-DD` |
| References | What did I encounter? | `References/@citekey` (Zotero) |
| Common | What idea is emerging? | `Common/<claim as a sentence>` |
| Projects | What am I trying to make happen? | `Projects/` |
| Bet | What am I risking on what I believe? | properties on a Project |

## Capture
- **New thought:** `Ctrl/Cmd+N` (Unique note creator) → write the core idea in `aliases`, then the thought. Add `#tags` at the end.
- **Continue a thought:** `Ctrl/Cmd+O` and type its idea — aliases are searchable — then append below a `---` with today's date.
- **Today:** `Ctrl/Cmd+Shift+D` opens the Daily note, which indexes itself.
- **Quote with no Zotero source** (something said, a post, a sign): Quick Note with `#quote` and the `source` property filled.
- **Anything you'd cite** (book, paper, article, podcast, video): save to Zotero, highlight there, import with Zotero Integration.

## Review loop
**Daily — 2 min, end of day.** Open today's Daily note. Give any untitled note an alias, any untagged note a tag. Add `#promote` to anything that felt bigger than a passing thought.

**Weekly — 20 min.**
- [ ] Clear *Needs a title or tag* (below).
- [ ] Open the **Tags** pane, sort by frequency. Note any tag that grew this week.
- [ ] Work through *Flagged to promote* using the promotion rules below. Remove `#promote` once handled.
- [ ] Import new Zotero annotations; write a synopsis for any reference you finished.
- [ ] Touch one *Common in progress* note: rewrite its current understanding.
- [ ] Check *Bets due for review*. Update each bet's log, then continue, adjust, or kill it.
- [ ] Look at *Candidates*: start one, drop one, or leave them.

**Quarterly — 45 min.** Read *Project archive* outcomes and "What I learned" sections. Promote durable lessons to Common. Move any Common note you'd stake a project on to `maturity: stable`.

## Promotion to Common
Promote when **any one** is true:
1. **Rule of three** — a tag or theme shows up in 3+ Quick Notes across at least 2 different weeks.
2. **Link pull** — you go to write `[[an idea]]` and it doesn't exist yet. Create it on the spot as a seed.
3. **Convergence** — your own note and 2+ references point at the same idea.
4. **Use** — you need the idea for writing or a project.

How to promote:
1. Name it as a **claim**, not a topic: *Excellence Becomes Play*, not *Excellence*.
2. Fill `gathers` with the tags it collects; notes carrying those tags appear automatically.
3. Write 1–3 sentences of current understanding. A seed can stop there.
4. Leave the Quick Notes where they are. Link to the Common note from any that matter.

Maturity: `seed` (a claim and a sentence) → `developing` (own synthesis, tensions, sources) → `stable` (you'd defend it in writing).

## Tags vs links
- **Tags** classify: `#competition #mastery`. Use freely.
- **Links** assert a relationship: "This reminded me of [[Physics of Grappling]]." Don't link just because two notes share a topic — that's what tags are for.

## Success criteria
The vault is working if you can:
- Capture a thought in seconds.
- Find related thinking through tags and links.
- Preserve external sources and annotations.
- Recognize recurring ideas.
- Promote recurring ideas into Common.
- Build increasingly sophisticated Common notes over time.
- Generate writing, research, and projects from accumulated understanding.
- Maintain the system with minimal administrative overhead.
